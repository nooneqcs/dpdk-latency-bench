> 本页为唯一结果页：第一节为对外口径（与简历逐条一致），第二节之后为原始记录与批次差异。
> 不同批次有 0.1%–0.7% 正常波动；**不同段的数字不可相加、不可互相推导**。

## 四、其他批次记录

### 1518B 帧
```
line_rate1518（PKT_LEN 1500 => 1518B 帧），i210 1G 全双工
三轮均为 opackets 410117 / 5s = 82023 pps，三轮完全一致
理论 81274 pps（(1518+20)*8）；实测约 100.9%（含前导/IFG 口径差），对外表述"达 1G 线速"
注意：程序打印的 5.51 分母是 64B 线速 1488095，对 1518B 无意义，禁引用
```

### parse20 解析
```
80 字节 / 20 字段大端报文
净 8.89 ns/条；绝对 10.57 ns；0.445 ns/字段；约 112.4 Mops
口径：i5-7400 单线程，L2 热 + 批量摊薄；DRAM 场景约 60–80 ns
优化链：14.90 → 8.89 ns（AVX2 批量定点 + 结构体压至 64B 单 cache line）
```

### 处理段与 rx_burst
```
单包处理段 ~140 ns（不含收包、不含真实发送/线缆，仅解析 + 描述符提交）
rx_burst 取包 p50 172 / p99 487 ns（单列，不与处理段相加）
另一口径：处理段 250 ns（100 pps）/ 166 ns（高频），含真实发送提交，条件不同
```

### 环满持续发送
```
环满持续发送 1.415 Mpps；启用 tx_done_cleanup 主动回收后 1.421 Mpps（+0.4%）
结论：瓶颈在端口/PMD，不在环回收
```

## 五、作废 / 禁止引用

| 数值 | 原因 |
|---|---|
| 2.96 ns | 曾标"SPSC 单次入队"，条件不可复现 |
| 36 / 170(=36+130) / 163 / 58 | 早期混合口径 |
| 10.35 ns（parse20 v4） | attic 快照不可编译，被 clean 版 8.89/10.57 取代 |
| 150 / 450–460 ns（rx_burst） | 偏乐观约 17%，改 172 / 487 |
| 141.7 ns（当作端到端用） | 141.7 是 tx_burst 单包，不是端到端 |
| 1,420,485 pps（95.46%） | 早期版本，已被 1,488,137 取代 |

**不可相加**：取包 172、解析 12、发送 210、处理段 140 等来自不同条件，任何"172+12+210=…""140+…=…"式的推导均无效。
